# 📌 Projects Included

## 1. SQL Major Project – Online Retail Application Database

### Project Overview

The major project focuses on developing a database for an online retail application using SQL.

The database is designed to manage customer information, product details, orders, payment information, and customer feedback.

### 🎯 Objectives

- Create and manage a relational database.
- Store customer information.
- Maintain product details and prices.
- Manage customer orders.
- Establish relationships between database tables.
- Store customer feedback.
- Perform data insertion and retrieval using SQL queries.

### 🛠️ Database Tables

The project includes the following tables:

| Table | Description |
|---|---|
| Customer | Stores customer ID, name, email, contact number, and shipping address. |
| Product | Stores product ID, name, description, price, and quantity. |
| Orders | Stores order details, customer information, shipping address, status, and payment amount. |
| Feedback | Stores customer feedback and product-related comments. |

### 💻 SQL Operations Performed

- Database creation
- Table creation
- Primary key and foreign key concepts
- UNIQUE and NOT NULL constraints
- CHECK constraints
- INSERT statements
- SELECT statements
- Data retrieval and management

### Expected Outcome

The project demonstrates how SQL can be used to organize and manage customer, product, order, and feedback information in a relational database.

## 2. SQL Minor Project – SQL Fundamentals and Queries

### Project Overview

The minor project focuses on understanding SQL and implementing its fundamental commands and operations.

It demonstrates different categories of SQL commands, SQL functions, and practical examples of updating and deleting records.

### 🎯 Topics Covered

**1. Introduction to SQL**
- Meaning of Structured Query Language
- Features and applications of SQL
- Different SQL implementations

**2. Data Definition Language (DDL)**
- CREATE
- ALTER
- DROP
- TRUNCATE

**3. Data Manipulation Language (DML)**
- SELECT
- INSERT
- UPDATE
- DELETE

**4. Data Control Language (DCL)**
- GRANT
- REVOKE

**5. Transaction Control Language (TCL)**
- COMMIT
- ROLLBACK
- SAVEPOINT

**6. SQL Functions**

Aggregate Functions:
- COUNT()
- SUM()
- AVG()
- MAX()

Scalar Functions:
- UPPER()
- LOWER()
- LENGTH()
- ROUND()

**7. Practical SQL Queries**

DELETE Query:
Used to remove unwanted records from a database table.

UPDATE Query:
Used to modify existing records in a database table.

### Expected Outcome

The project provides practical exposure to SQL commands and demonstrates how database records can be inserted, retrieved, updated, and deleted.
